## 🏛️ EBOOKFOUNDATION REPOSITORY — `GITHUB → WEBSITE → SEARCH`

The most comprehensive and well-known resource for free programming books, maintained by the non-profit Free Ebook Foundation. It is one of GitHub's most popular repositories, with nearly **400,000 stars**, and lists thousands of freely available books in many languages .

- **GitHub Repository** — `EbookFoundation/free-programming-books` 
- **Readable Website** — `ebookfoundation.github.io/free-programming-books/` 
- **Search Tool** — `ebookfoundation.github.io/free-programming-books-search/` 
- **License** — Content is licensed under CC BY 
- **How It's Organized** — Books by Programming Language (C++, C#, Python, Java), Books by Subject (Algorithms, AI, Cloud Computing, Compiler Design, Data Science), and Other Resources (Cheat Sheets, Free Online Courses, Interactive Programming Resources, Problem Sets, Podcasts, Programming Playgrounds) .

`GITHUB → WEBSITE → SEARCH`

## 💡 Why Choose Free Programming Books?

Programming education should not be locked behind a paywall. The EbookFoundation repository has spent years curating thousands of freely available books across every major language and subject—from algorithms to AI—and it remains one of GitHub's most starred projects. This guide consolidates that repository, the curated awesome-programming-books list, and proven language-specific picks like A Byte of Python into one reference. Whether you're starting your first language or deepening a specialization, this guide maps the sources.
